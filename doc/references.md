## Further reading

- [Yakindu statecharts](https://www.itemis.com/en/yakindu/state-machine/documentation/user-guide/overview_what_are_state_machines)
  YAKINDU Statechart Tools is a tool for specifying and developing
  state machines.
- [Developing Reactive Systems Using Statecharts](http://msdl.cs.mcgill.ca/people/hv/teaching/MoSIS/lectures/StatechartsModellingAndSimulation.pdf)
  a well-made English course on statecharts.
- [Modéliser les vues dynamiques d'un système](http://niedercorn.free.fr/iris/iris1/uml/uml09.pdf)
  an introduction to UML statecharts in French.
- [UML/SysML Diagramme d'état Programmation Arduino](https://eduscol.education.fr/sti/ressources_pedagogiques/umlsysml-diagramme-detat-et-programmation-arduino#fichiers-liens)
  a French course on statecharts with companion source code.
- [State Machine Design in C++](https://www.codeproject.com/Articles/1087619/State-Machine-Design-in-Cplusplus-2)
  the original inspiration for the legacy `StateMachine.hpp` shipped
  with [PlantUMLStatecharts](https://github.com/Lecrapouille/PlantUMLStatecharts).
- [Towards Efficient Code Synthesis from Statecharts](https://cs.emis.de/LNI/Proceedings/Proceedings07/TowardEfficCode_3.pdf)
  research paper on generating state machine code.
- [Real-Time Structured methods: Systems Analysis](https://www.amazon.com/Real-Time-Structured-Methods-Analysis-Engineering/dp/0471934151)
  by Keith Edwards, Edition Wiley 1993.
- [Structured Analysis for Real Time](https://www.espacetechnologue.com/wp-content/uploads/2017/03/2_DeveloppementApp_STRv11.pdf).
- YouTube: [UML Behavioral Diagrams: State Transition Diagram](https://youtu.be/OsmWASXE2IM)
  and [State Transition Diagram](https://youtu.be/PF9QcYWIsVE) (Georgia
  Tech Software Development Process).
